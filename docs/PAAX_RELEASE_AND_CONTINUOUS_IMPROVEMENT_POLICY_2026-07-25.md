# PAAX Release and Continuous Improvement Policy

A release is blocked by: secret finding, corrupted ZIP, source PDF mismatch, PLHUT bootstrap regression, cross-project access, unauthorized Measurement Fact entering Core Engine, exact K2 regression, invalid units, unsupported numerical claims, failed rollback, or critical test regression.

Rollout uses feature flags and shadow mode. Formula/model/prototype versions are reversible. Corrections enter an error corpus with project scope, evidence, model version, and reviewer reason; they do not become universal rules automatically. Production incidents require containment, audit preservation, root-cause analysis, regression test, and explicit release decision.
