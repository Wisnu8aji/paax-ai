# PAAX

I'm building PAAX as a desktop AI agent workspace for civil engineering and construction.

The project comes from my interest in Civil Engineering and in how an agent can help with project work. My current focus is the agent foundation and Command Room, with Chat and Works inside an Electron desktop application.

I'm working on tool use, context, planning, file interaction, task execution, and a more reliable desktop experience. These parts are still being developed and tested.

Deeper engineering capabilities will follow as the foundation becomes ready. There is still research to do, and some directions may change as I learn more.

PAAX is in active development. Its implementation is private; this repository is the public project overview.

Development line: 0.6.0.
